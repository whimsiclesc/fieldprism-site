# fieldprism-site

This repository holds the public privacy policy for FieldPrism, a personal-use video grading app for iPhone by Kellen Lor.

- `index.html` is the policy page (also served at the site root).
- `privacy.html` is an identical copy, so `/privacy.html` works too.
- It is a single self-contained page: no scripts, fonts or trackers.

Contact: fieldprism.app@gmail.com
